= Architecture memory

Derived from arc42 and linked ADRs for efficient retrieval. Edit source documents first and refresh both derived files afterward.

== goals

Generate local intermediary JSON during Maven builds with reliable failure.
Source: link:arc42/01-introduction-and-goals.adoc[arc42].

== constraints

Public DendroDocs repo, MIT, Maven Central, JDK21+, Maven3.9.11+, UTF-8 Java21 sources.
Source: link:arc42/02-architecture-constraints.adoc[arc42].

== context

Maven supplies roots and dependencies; analyzer produces schema-validated per-root JSON.
Source: link:arc42/03-context-and-scope.adoc[arc42].

== strategy

Resolve standalone analyzer, syntax preflight, detect omitted top-level types, isolate process, stage and merge output.
Source: link:arc42/04-solution-strategy.adoc[arc42].

== building blocks

GenerateMojo, AnalyzerProcess, Maven Resolver, JDK compiler, Jackson, external analyzer.
Source: link:arc42/05-building-block-view.adoc[arc42].

== runtime

Skip POMs, normalize roots, adapt class directories, validate, analyze, merge, replace, cleanup.
Source: link:arc42/06-runtime-view.adoc[arc42].

== deployment

Plugin in Maven, analyzer in child JVM; CI on Windows/Linux; manual Central staging.
Source: link:arc42/07-deployment-view.adoc[arc42].

== cross cutting

Per-module workspaces, no analyzer classes in Maven realm, schema owned upstream.
Source: link:arc42/08-crosscutting-concepts.adoc[arc42].

== decisions

ADR001 isolation and ADR002 reliable generation are proposed and implemented for review.
Source: link:arc42/09-architectural-decisions.adoc[arc42].

== quality

Executable coverage of errors, reactors, roots, paths, timeout, and offline reuse.
Source: link:arc42/10-quality-requirements.adoc[arc42].

== risks

OSV matches in four analyzer components block releases; reachability and large-project timings unknown.
Source: link:arc42/11-risks-and-technical-debt.adoc[arc42].

== glossary

Mojo, reactor, intermediary JSON, source root, standalone analyzer, schema, class directory, fresh output.
Source: link:arc42/12-glossary.adoc[arc42].

== Defaults and decisions

Use Java 21 syntax, JDK 21+, Maven 3.9.11+, UTF-8, and the pinned standalone analyzer 0.1.0.
These implemented defaults are documented in arc42; isolation and staged output ADRs remain proposed for maintainer review.
Use Markdown guides, AsciiDoc architecture, and PlantUML.

== Open questions

Resolve analyzer advisory matches before production staging.
Verify Windows/Linux CI, Central credentials, signing, environment reviewers, and branch protection.
Large-project latency, complete analyzer syntax support, and renderer coverage remain unmeasured.
