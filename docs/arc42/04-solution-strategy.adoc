= Solution strategy

== Integration strategy

Reuse the published analyzer and isolate its shaded libraries in a child JVM.
Bind generation to process-classes so generated sources and reactor class directories exist.
Use the JDK compiler's parse-only API to reject malformed input before the analyzer can silently omit it.
This syntax check does not perform annotation processing or replace structural analysis.

== Output strategy

Analyze separate non-overlapping source roots into fresh temporary files.
Require each root's output to exist and parse as a JSON array, check that top-level declarations were not omitted, then merge with duplicate detection.
Replace the destination only after the complete result is ready.
Preserve the previous file on failure and fail the build.

== Operational strategy

Use module-local temporary files, Maven Resolver for offline/mirror compatibility,
per-root process timeouts, a generated help goal, and Invoker consumer builds.
