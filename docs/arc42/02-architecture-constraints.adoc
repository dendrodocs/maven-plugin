= Architecture constraints

== Organizational constraints

Create a separate public repository in the DendroDocs organization.
Use MIT licensing and Maven Central as the artifact registry.
Do not copy or fork the Java analyzer implementation.

== Technical constraints

Build with JDK 21+ and Maven 3.9.11+ in the Maven 3 series.
Use released dev.dendrodocs:tool:0.1.0 as the default analyzer.
Allow a concrete standalone JAR artifact, including an optional classifier, through toolArtifact.
Every selected tool must implement link:../tool-contract.md[the common CLI and JSON contract] and run on the JDK used by Maven.
Run its standalone JAR in a child JVM; resolve it through Maven's plugin repositories.
Enable UTF-8 Java 21 syntax preflight automatically for dev.dendrodocs:tool; other tools own language validation.
The validateJava override explicitly enables or disables Java preflight and declaration completeness checks.
Maven supplies its own APIs and repository session.
The adapter must not introduce changes to the shared intermediary JSON schema.

== Conventions

Usage guides use Markdown, architecture uses AsciiDoc, and diagrams use PlantUML.
Java packages live under dev.dendrodocs.maven.
