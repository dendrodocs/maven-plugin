= Building block view

== Level 1

GenerateMojo:: Maven configuration, syntax checks, source selection, classpath adaptation, merge, and destination replacement.
AnalyzerProcess:: Child JVM lifecycle, timeout, diagnostics, and fresh-output requirement.
DendroDocs Java tool:: Standalone structural analysis and schema validation.
Maven Resolver:: Artifact resolution using Maven's configured session and plugin repositories.
JDK compiler:: Syntax-only preflight; no semantic attribution or generated bytecode.
Jackson:: Strict JSON array parsing and formatting.

== Test building blocks

JUnit tests isolate adapter failure behavior.
Invoker fixtures execute the actual plugin in separate consumer Maven builds.
